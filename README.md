# Daily Activity Health Predictor

## About the Project

This project is a simple Machine Learning application that predicts whether a person’s daily lifestyle is healthy or unhealthy based on their routine.

In everyday life, we often overlook small habits such as walking, sleep patterns, or screen time. Over time, these habits have a significant impact on our health, but we may not always realize it. This project aims to address that by providing a quick and basic health prediction using daily activity data.


## What It Does

The system takes user inputs such as:

- Steps walked  
- Sleep hours  
- Screen time  
- Water intake  
- Exercise  
- Junk food consumption  

Based on these inputs, the model predicts:

- Healthy Lifestyle  
- Unhealthy Lifestyle  
 

## Dataset

The dataset used in this project is self-created and based on realistic daily habits.

It includes the following features:

- Steps  
- Sleep Hours  
- Screen Time  
- Water Intake  
- Exercise (1/0)  
- Junk Food (1/0)  
- Health (Output)

## Example Input
Steps walked: 8000  
Sleep hours: 7  
Screen time: 3  
Water intake: 3  
Exercise: 1  
Junk food: 0  


## Output
Healthy Lifestyle
